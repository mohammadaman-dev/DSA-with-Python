### 1. Two Sum

- Platform: LeetCode
- Topic: Array
- Difficulty: Easy
- Approach: Brute Force
- Description:
  - Find two numbers in an array whose sum is equal to the given target.
  - Return the indices of those two numbers.

- Time Complexity: O(n²)
- Space Complexity: O(1)

- Platform: LeetCode
- Topic: Array
- Difficulty: Easy
- Approach: Linear Search
- Description:
